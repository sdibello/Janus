# 0058: Desktop and laptop support for the first release

- Date: 2026-09-26
- Status: Accepted
- Related specs: [Release requirements](../specs/README.md)

## Context

The review clarified which device categories the first release must support.

## Decision

The first release supports desktop and laptop computers only. Tablet and phone support are outside the initial scope.

## Alternatives considered

- Including tablets: not chosen for the first release.
- Including tablets and phones: not chosen for the first release.

## Consequences

Design and validation target desktop and laptop workflows. This does not select operating systems, browsers, a technology stack, or a deployment model. Offline requirements remain a separate open question.
