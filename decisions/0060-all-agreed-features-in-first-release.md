# 0060: All agreed features in the first release

- Date: 2026-09-26
- Status: Accepted
- Related specs: [Release requirements and feature index](../specs/README.md)

## Context

The review clarified whether the first usable release should deliver all agreed features or a smaller subset.

## Decision

The first usable release includes all agreed features across specs 001 through 007: accounts and access administration, campaigns and characters, encounters, initiative and turn ordering, HP tracking, and showing the encounter UI through external screen sharing.

## Alternatives considered

- Delivering a smaller feature subset as the first usable release: not chosen.

## Consequences

Implementation can proceed in increments, but first-release acceptance covers all agreed features. Previously deferred features remain outside scope. This decision does not approve unresolved proposals in draft specs, add built-in broadcasting, or select implementation technologies.
