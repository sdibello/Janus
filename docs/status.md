# D&D 3.5 status reference

The battle status catalog uses **D&D 3.5**, confirmed on 2026-10-17. The source of truth is [shared/conditions.json](../shared/conditions.json): both the web UI and Campaigns API use that file, including labels, short effect reminders, and rule links.

## Scope and sources

The catalog contains all **38 entries** in the [3.5 SRD Condition Summary](https://www.d20srd.org/srd/conditionSummary.htm), plus four tags already present in Janus's reference: Dehydrated, Diseased, Poisoned, and Rebuked. These are combat-relevant reference tags, not four additional entries in the SRD's condition-summary chapter. Spell-specific buffs and every possible spell effect are outside this catalog.

Additional references, checked 2026-10-17:

- [Combat modifiers](https://www.d20srd.org/srd/combat/combatModifiers.htm): attack, AC, concealment, and prone reminders.
- [Special abilities](https://www.d20srd.org/srd/specialAbilities.htm): ability effects, negative levels, disease, poison, incorporeality, and paralysis.
- [Grappling and turning/rebuking undead](https://www.d20srd.org/srd/combat/specialAttacks.htm): restricted actions and undead-specific effects.
- [Starvation and thirst](https://www.d20srd.org/srd/environment.htm#starvationAndThirst): dehydration and nonlethal damage.

These pages reproduce the 3.5 System Reference Document. The summaries are short reminders, not replacements for the originating effect, complete rules, exceptions, or immunity checks. Rule links are available from each active participant's effect summary. The reference pages identify their text as Open Game Content under the [Open Game License](https://www.d20srd.org/ogl.htm).

## Compatibility and corrections

- **Grappled** retains its existing saved identifier and label; its 3.5 reference is **Grappling**. Existing Invisible, Grappled, and Prone records need no migration.
- Deafened automatically fails Listen checks; it is not a universal −10 Listen penalty. Blinded automatically fails vision-dependent checks, including Spot; Search and most Strength/Dexterity skill checks have the separate −4 penalty in the full rule.
- Prone includes different AC modifiers against melee and ranged attacks. Paralyzed still permits purely mental actions. Dazed does not have a mandatory one-round duration; duration depends on its cause.
- Incorporeality and petrification have important exceptions. The old reference's blanket petrification hardness/immunity claims are not applied by Janus.
- Disabled, Dying, and Dead can be recorded manually like other catalog conditions. Janus's existing HP-derived Disabled/Dying/“alive adjacent” presentation is unchanged: HP at or below −10 does **not** automatically apply Dead. “Alive adjacent” is a Janus house status, not an SRD condition.
- The active card's second row holds Next/Skip and a summary of all its manually applied conditions plus HP-derived state. Duplicate manual/derived labels appear once in that effect summary. Other participants do not show effect summaries.
- These are **manual rules reminders**. They do not change attacks, AC, ability scores, HP, movement, or button availability. The DM resolves the referenced effects; Next/Skip remain explicit actions even when a condition would restrict actions in the rules.
- A status bubble's numeric count is the number of that participant's Next actions while applied. It is not an ability-damage amount, negative-level count, exhaustion severity, or automatic duration/expiry. Origin-specific details remain for the DM to track.
